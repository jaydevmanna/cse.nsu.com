# cse.nsu.com

## Overview

- Interactive login and surprise reveal
- Customizable dashboard with gallery, notes, timeline, and countdown timer
- Built with plain HTML, CSS, and JavaScript
- Configured for static hosting with Netlify using `netlify.toml`

## Files

- `index.html` — main page markup
- `styles.css` — page styling
- `script.js` — interactive behavior and localStorage handling
- `netlify.toml` — Netlify publish configuration
